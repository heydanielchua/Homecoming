One click from a listing

Instead of selecting the whole listing and pasting it, click one button on the listing page and Listing Check opens with the asking price, size and details already in.

Put it on your bookmarks bar

  1. Show the bookmarks bar if it is hidden — Ctrl+Shift+B, or ⌘+Shift+B on a Mac.
  2. Drag this button up onto it:

    Check this flat
  3. Open any 99.co or PropertyGuru listing and click it. This site opens in a new tab with the flat filled in.

On a phone, or if dragging will not work

Make a new bookmark of any page, edit it, name it Check this flat and replace its address with the text below. Then open a listing and pick that bookmark.

What it does, and does not do

It runs in your browser, on a page you already have open, and keeps only the lines that look like a listing's figures — the price, the floor area, the details table — which it hands to this site in the address. Nothing is sent anywhere else, no listing is ever fetched by a server, and nothing is stored. It is the same thing as copying the page yourself, with the keystrokes taken out.

Some sites refuse to run bookmarklets at all, as part of their security settings. If clicking it does nothing, that is why, and copying the page by hand still works.
